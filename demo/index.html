allons-y.css Demo

allons-y.css is a minimal, themeable CSS file for readable, vertical content. This demo uses Miriam Libre for all text, and may take some tweaking for a different font. The colors (except the mesh background, which I made with [this tool](https://www.learnui.design/tools/mesh-gradient-generator.html)) are set by CSS variables and adapt to light or dark mode.

How it works

  • Color variables: --color-bg (background), --color-fg (foreground/text), --color-accent (links, highlights), --color-muted (secondary text), --color-block (block backgrounds), --color-border (borders)
  • .stack utility: Adds vertical spacing between direct children using margin-top: var(--flow-space, 1em)
  • Theme switch: Click the button above to toggle between light and dark mode (overrides system preference)

Typography

Headings, paragraphs, lists, tables, and blockquotes are all styled for readability. The only font used is Miriam Libre (sans-serif).

Code

Inline code and code blocks use --color-block for background.

Customizing

You can override any color variable or utility in your own CSS. For example, to change the accent color: 

:root {
            --color-accent: #ff5a36;
        }

Try it yourself

Use allons-y.css as a base for your own site. Add your own colors, fonts, or layout as needed. For more info, see the README.
